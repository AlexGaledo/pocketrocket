How it works

1

Install

Download the Windows installer, or run from source on any OS.

2

Sign in to Claude Code

Run claude once to log in with your subscription, or set an API key.

3

Create a bot and chat

Everything stays local in %APPDATA%\com.pocketrocket.app.

Run on a server

Run the hub on a Linux box as a systemd service with a virtual desktop, so routines fire while your laptop is closed and bots get Browser and Desktop tools. Reach it over an SSH tunnel — the hub never needs to be exposed to the internet.

Frequently asked

Is it free?
Yes. PocketRocket itself is free and open source; you pay for Claude usage through your existing subscription or an API key.
Do I need to create an account?
No. Everything works fully signed out. Signing in from Settings → Account is optional and only used for account features, like paid plans later.
Does it phone home?
The hub runs on your machine and only talks to Claude and the GitHub releases page. If you choose to sign in, your email goes to Supabase (our auth provider) to complete the sign-in — nothing else, and bot conversations, files and keys never leave your machine. No telemetry.
Windows SmartScreen warning?
The installer is unsigned, so SmartScreen may warn. Click "More info" then "Run anyway," or build from source if you'd rather skip that.
Which model is cheapest?
Haiku 4.5 is the fastest and cheapest; Sonnet 5 is the default balance of quality and cost; Opus 5 and Fable 5.1 cost more. Set the model per bot in the bot dialog.
