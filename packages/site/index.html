Up and running in a few minutes

Toki walks you through setup the first time you open it.

  1. Download Toki

    Get the Windows installer above. On Mac or Linux, run it from source.

  2. Connect Claude

    Sign in to Claude Code once. Toki checks it's ready and lets you know.

  3. Say hi to your first helper

    Pick a starter helper or make your own, then start chatting.

Toki isn't code-signed yet, so Windows may show a SmartScreen notice the first time. Choose More info, then Run anyway.

Questions

Is it free?
Yes. Toki is free and open source under the MIT licence. Your helpers use your own Claude subscription or API key.
Do I need an account?
No. Everything works without one. You can sign in later from Settings if you want account features.
Where do my conversations go?
Nowhere new. Toki talks to Claude to get replies and checks GitHub for updates. Your chats, files and keys stay on your computer, and there's no tracking. If you choose to sign in, only your email is shared to do that.
Can my helpers keep working while my laptop is closed?
Yes, if you run Toki on an always-on machine at home or in the cloud. Routines keep firing and you can check in from anywhere. Here's how.
Windows says it protected my PC. Is that okay?
That's SmartScreen meeting a new app it hasn't seen signed. Choose More info, then Run anyway. If you'd rather not, you can build Toki from the source on GitHub.
