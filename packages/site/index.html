A crew of AI bots that checks with you first.

PocketRocket is a messenger for a team of Claude bots that you host yourself. Put them in group chats, give each one memory, skills and a schedule, and approve anything risky before it happens.

Download for Windows Self-host on a server

Free and open source under MIT. Needs Windows 10 or 11 and a Claude Pro or Max plan, or an Anthropic API key.

How it works

  1. Make a room

    A room is a group chat. Message one bot directly, or put a few together on a job. A message with no @mention goes to the room's coordinator, so something always picks it up.

  2. Give it bots

    Each bot has a name, a role, its own private memory and the skills you hand it. Bots @mention each other and hand off work, the way a small team would.

  3. Approve what matters

    Before a bot runs a shell command, edits outside its workspace or changes your team, an approval card appears in the chat. Allow once, allow for the session, or deny.

The guard rails, and where they stop

Treat every bot like a contractor with a shell on your machine. These guards catch honest mistakes. They are not a wall against a model that has been tricked by something it read.

  • Approval cards

    On by default for shell commands, edits outside the workspace and changes to your team. From the next release, routine and trigger turns always ask, even with approvals bypassed.

    Limit Bypass mode turns them off for a bot. It's opt-in, clearly labelled, and has no undo.

  • PC runner Next release

    A bot on your server can ask your own Windows PC to run a job, only in folders you list. You approve it in PocketRocket, then again in a dialog on the PC. No answer in 10 minutes means no.

    Limit Once you press Run, Claude edits files in that folder with the tools you allowed. Pick those folders with care.

  • Secret-file guard Next release

    Bots can't read or write the hub's key files or a project's .env files with their file and shell tools, in any approvals mode.

    Limit It covers the ordinary ways to read those files. A command that builds the file name at run time can still get past it.

  • Key kill switch Next release

    On a server, one script lists every key the hub holds by name, moves them all out at once, and puts them back later or shreds them.

    Limit Moving a key only stops this server using it. Copies, including backups, still work. Rotate each key with its provider.

  • Local by design

    The hub listens on 127.0.0.1 only and always needs a token. Your chats, files and keys stay on your PC or server. No telemetry.

    Limit Never open the hub's port to the internet. Reach a server over SSH or your own Tailscale network.

On this PC

Everything runs and stays on your Windows computer. About five minutes from download to first chat.

Questions

Is it free?

Yes. PocketRocket is free and open source under MIT. Bots run on your own Claude subscription or API key, so that's the only cost.

Which AI models does it use?

Claude, through the Claude Code you already have. Sonnet 5 is the default, and you can pick Opus 5 or Haiku 4.5 per bot. Adapters for Codex, OpenCode and Grok exist in the code for development only: they're off by default, not offered in the app, and Codex and Grok haven't been tested against real accounts.

Does it work on macOS or Linux?

The only installer today is for Windows. On macOS and Linux you can run it from source; the development guide shows how. Servers run on Linux.

Is it a sandbox?

No. Approval cards and workspace rules catch a bot making an honest mistake. A bot that has been prompt-injected by a web page, email or file can find ways around them. Give each bot the least access it needs, and never give the Browser or Desktop tool to a bot that reads untrusted content.

Does it send my data anywhere?

Bot turns go to Claude. Beyond that, the hub only calls services you turn on yourself, such as an integration you connect or the optional account sign-in. Chats, files and memory stay on your machine or server. There's no telemetry.

Why does Windows warn me about the installer?

The installer isn't code-signed yet, so SmartScreen says "Windows protected your PC". Choose More info, then Run anyway, or build it from source.

How do I update?

There's no auto-updater yet. Check for updates in the tray menu opens the releases page; run the newer installer over the old one. Your bots, chats and settings are kept.
