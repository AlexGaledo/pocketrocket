How it works

1

Install

Download the Windows installer, or run from source on any OS.

2

Pick a provider you're already logged into

Claude, Codex, OpenCode, or Grok — subscription or API key.

3

Create a bot and chat

Everything stays local in %APPDATA%\com.pocketrocket.app.

Run on a server

Run the hub on a Linux box as a systemd service with a virtual desktop, so routines fire while your laptop is closed and bots get Browser and Desktop tools. Reach it over an SSH tunnel — the hub never needs to be exposed to the internet.

Frequently asked

Is it free?
Yes. PocketRocket itself is free and open source; you pay your provider (Claude, OpenAI, OpenCode's own billing, or xAI) for the model usage.
Does it phone home?
No. The hub runs on your machine and only talks to the provider you configured. No telemetry, no accounts.
Windows SmartScreen warning?
The installer is unsigned, so SmartScreen may warn. Click "More info" then "Run anyway," or build from source if you'd rather skip that.
Which model is cheapest?
Depends on the provider: fast/mini tiers (e.g. a small Claude model, GPT-5 mini-class, Grok's fast tier) are cheapest per bot. Check each provider's pricing page for current rates.
